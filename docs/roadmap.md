# План

## Этап 0. Подготовка дома (без кода)
- [ ] PS5 подключить к роутеру **кабелем** (ПК уже на кабеле).
- [ ] На PS5: **Настройки → Система → Дистанционное воспроизведение → Включить**.
- [ ] Чтобы будить консоль из программы: **Настройки → Система → Энергосбережение →
      Функции в режиме покоя → Оставаться подключённым к интернету** и **Разрешить
      включение PS5 по сети**.
- [ ] Узнать IP-адрес PS5: **Настройки → Сеть → Статус соединения**.
- [ ] Узнать свой PSN account ID (его можно найти вручную или войти в PSN из программы).
- [ ] Во время игры выключать VPN на ПК.
- [ ] Для сборки: Visual Studio Build Tools (C++) и CMake.

## Этап 1. Каркас и связь с PS5
- [ ] Каркас проекта: CMake, ядро chiaki-ng (только сеть), лицензия AGPL-3.0.
- [ ] Консольная утилита: найти PS5, разбудить, привязать по PIN, подключиться, нажать
      кнопку ✕.
- **Выход этапа:** PS5 реагирует на нажатия из нашей программы.

## Этап 2. Ввод и мышь → стик
- [ ] Поток ввода: Raw Input, тик 1 мс, захват и защита фокуса ([architecture.md §2](architecture.md)).
- [ ] Цепочка мышь → стик со степенной кривой ([architecture.md §3](architecture.md)).
- [ ] Раскладка из JSON-профиля.
- [ ] Режим «без консоли» с визуализатором стика. Его можно делать и тестировать без PS5.
- **Выход этапа:** можно играть в GTA 6 с клавиатуры и мыши.

## Этап 3. Кривая и калибровка
- [ ] Адаптивное сглаживание, форма мёртвой зоны (круг/квадрат), перенос остатка.
- [ ] Живая настройка в игре: клавиша выбирает параметр, колёсико меняет значение, голос называет значение ([architecture.md §4](architecture.md)).
- [ ] Тесты «круг» и «сдвиг».
- [ ] Кривая через таблицу (LUT): замер полного оборота камеры при разных наклонах.
- [ ] Пресет `gta6.json`.
- **Выход этапа:** одинаковое движение мыши даёт одинаковый поворот на любой скорости.

## Этап 4. Профили под GTA 6

- [ ] Раскладка как в GTA на ПК.
