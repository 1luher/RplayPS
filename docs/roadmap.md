# План

## Этап 0. Подготовка дома (без кода)
- [ ] PS5 подключить к роутеру **кабелем** (ПК уже на кабеле).
- [ ] На PS5: **Настройки → Система → Дистанционное воспроизведение → Включить**.
- [ ] Чтобы будить консоль из программы: **Настройки → Система → Энергосбережение →
      Функции в режиме покоя → Оставаться подключённым к интернету** и **Разрешить
      включение PS5 по сети**.
- [ ] Узнать IP-адрес PS5: **Настройки → Сеть → Статус соединения**.
- [ ] Узнать свой PSN account ID (в keyboard-ds5 есть инструкция, можно и через вход в PSN).
- [ ] Во время игры выключать VPN на ПК.
- [ ] Установить Python 3.11: `winget install -e --id Python.Python.3.11`

## Этап 1. Проверить keyboard-ds5 как есть
- [ ] Прочитать код и запустить из исходников (`setup.bat`, затем `app.bat`). Готовый exe не
      брать: он не подписан, а из исходников код виден целиком.
- [ ] Привязать PS5 (PIN с экрана консоли).
- [ ] Проверить: работают кнопки в меню, WASD и мышь в GTA 6.
- [ ] Записать впечатления: насколько плохо ощущается мышь на ~60 Гц со сглаживанием 35 мс.
- **Выход этапа:** понятно, работает ли связь с вашей консолью и прошивкой.

## Этап 2. Форк и прямое чтение мыши
- [ ] Форкнуть keyboard-ds5 (или перенести код сюда с сохранением AGPL-3.0 и авторства).
- [ ] Raw Input + LL-хуки + ClipCursor ([architecture.md §1](architecture.md)).
- [ ] Короткое окно скорости (4–8 мс), цикл 125 Гц.
- [ ] Режим «без консоли» с визуализатором стика.
- **Выход этапа:** мышь заметно отзывчивее, чем в оригинале.
