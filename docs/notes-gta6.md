# Заметки: GTA 6 с RPlay K&M

Заполняется дома после первой игры (план MVP, задача 8, шаг 4). Это вход для следующего
плана (калибровка).

## Проверка первой версии
- [x] `rplayctl discover` находит PS5 (2026-11-21, PS5 прошивка 14.23)
- [x] Привязка (account ID + PIN; `rplayctl pair`). Важно: account ID того пользователя PS5, под которым идёт игра
- [x] F8 → переключить монитор на PS5 → персонаж ходит на WASD
- [x] Камера крутится мышью (и `rplayctl stick`)
- [ ] ЛКМ стреляет, ПКМ целится
- [ ] Alt+Tab вслепую → тройной сигнал, персонаж останавливается
- [ ] PS5 выключили посреди игры → сигнал «связь потеряна»; включили → F8 переподключает
- [ ] Закрыли RPlay K&M посреди бега → персонаж останавливается
- [ ] Слышны все сигналы: захват вкл/выкл, связь есть, связь потеряна
