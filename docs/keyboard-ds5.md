# Разбор keyboard-ds5 (tejasbnshetty/keyboard-ds5)

Дата разбора: 2026-11-20. Коммит: `170993e` (2026-10-11, v0.1.0 pre-release).
Код только прочитан, ничего не запускалось.

## Что это
Windows-приложение на Python 3.11. Оно подключается к PS5 по протоколу Remote Play
**только для управления**: видео не принимается, игру смотрят на ТВ.
Окно приложения сделано на WebView2 (pywebview). Это веб-страница, которая общается
с локальным Python-сервером через WebSocket.

```
Мышь/клава → окно WebView2 (JS, pointer lock) → WebSocket 127.0.0.1 → Python (gameinput.py)
           → gamepad.py (пакеты состояния, до 125 Гц) → pyremoteplay 0.7.6 → PS5 по UDP
```

## Безопасность: в целом аккуратно
- Сетевые обращения только к трём адресатам:
  - PS5 в локальной сети;
  - files.pythonhosted.org: только в exe-сборке, по клику, с проверкой SHA-256;
  - auth.api.sonyentertainmentnetwork.com: вход в PSN, по желанию; account ID можно ввести вручную.
- Ключи из пакета pyremoteplay читаются как данные через `ast` и не исполняются. Хэши закреплены.
- Локальный сервер слушает только 127.0.0.1. Подключение требует случайного токена, проверяется Origin и Host.
- Логи вычищаются от токенов и PIN-кодов. Телеметрии не нашёл.
- `subprocess` используется только для перезапуска самого себя.
- Есть 24 файла тестов.
- Риски: exe без цифровой подписи; pyremoteplay 0.7.6 давно не обновлялся; использование может нарушать ToS PSN (автор сам об этом пишет).

## Мышь → стик (`ps5remote/gameinput.py`)
- Тилт стика задаёт скорость мыши, а не её положение.
- Скорость = движение за окно сглаживания (по умолчанию 35 мс, минимум 20 мс), делённое на это окно.
- Чувствительность X/Y. Полный наклон стика при 2000 отсчётов/с × чувствительность.
- Кривая: только `linear` или `exponential` (x²).
- `anti_deadzone` (минимальный наклон), `outer_limit`, `return_ms` (возврат к центру).

## Слабые места для «программного XIM»
1. **Мышь читается браузером**, а не через Raw Input. Автор сам пишет, что это ~60 отчётов в секунду.
   Поэтому минимальное сглаживание 20 мс, а это добавляет задержку и снижает точность.
   Raw Input дал бы 500–1000 Гц.
2. **Нет отдельной чувствительности при прицеливании** (пока зажата ПКМ). Профили переключаются только вручную.
3. **Кривая примитивная**: нет таблицы точек, нет учёта реальной кривой отклика игры, нет калибровки.
4. Окно приложения должно быть в фокусе на ПК. При потере фокуса всё отпускается, и это правильно.
5. Частота отправки стика ограничена 125 Гц. Для 30/60 FPS игры этого достаточно.
