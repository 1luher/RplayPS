# Архитектура (черновик)

Свой проект. Идеи собраны из других проектов, откуда что взято — в [best-of.md](best-of.md).

## Стек (решено)
| Что | Выбор | Почему |
|---|---|---|
| Язык | **C++20** | Ядро chiaki-ng на C встраивается напрямую, стабильный тик в 1 мс, один exe |
| Сборка | CMake + Visual Studio Build Tools (MSVC), Windows 10/11 x64 | Стандарт для Windows |
| Связь с PS5 | ядро chiaki-ng `lib/`, закреплённый коммит, только локальная сеть | Живой проект, чинят после прошивок |
| Криптография | Mbed TLS 2.28 | Как в сборке DirectView, без OpenSSL |
| Интерфейс | Dear ImGui + Direct3D 11 | Быстро делать ползунки, графики и визуализатор стика |
| Профили | JSON через nlohmann/json | Простой формат, можно править руками |
| Тесты | doctest | Один заголовочный файл, без лишних зависимостей |
| Лицензия | AGPL-3.0 | Требование ядра chiaki-ng |

Все сторонние библиотеки лежат в репозитории (`third_party/`) с закреплёнными версиями.
Во время сборки ничего не скачивается.

## Решения по умолчанию (можно поправить)
- Ядро chiaki-ng берём из оригинала на закреплённом коммите. Патчи для MSVC и Windows
  повторяем по примеру PS5-DirectView, с указанием авторства.
- Хранение данных в `%APPDATA%\RplayPS\`: настройки, профили, ключ привязки (защищён DPAPI).
- В первой версии PSN account ID вводится вручную. Вход через PSN — позже.
- Интерфейс на русском, позже можно добавить английский.
- Игра идёт на ТВ, а окно RplayPS — на мониторе ПК. Поэтому «оверлей» калибровки — это
  просто панель в нашем окне, рисовать поверх игры не нужно.

```
                 ┌──────────────────────── RplayPS ────────────────────────┐
Мышь  ─Raw Input─►│ [Скорость] ─► [Профиль] ─► [Форма/кривая/LUT] ─► правый стик │
Клава ─Raw Input─►│ [Раскладка] ─► кнопки, L2/R2, левый стик ───────────────────│─┐
                 │  поток ввода: MMCSS «Games», тик 1 мс                       │ │
                 └──────────────────────────────────────────────────────────────┘ │
                                                                                   ▼
                                  ядро chiaki-ng: состояние геймпада (≤125 Гц) ─► PS5
                                  видео и звук не принимаются, игра идёт на ТВ
```

## 1. Связь с PS5: ядро chiaki-ng
- Встраиваем только сетевую часть chiaki-ng:
  - поиск консоли, пробуждение, привязка по PIN;
  - сессия Remote Play и отправка состояния геймпада.
- Не берём видео, звук, интернет-режим, FFmpeg и curl. Как это сделать, показывает
  PS5-DirectView: заглушки + 3 патча.
- Обновление ядра после прошивки PS5 — отдельная инструкция в репозитории.
- PSN account ID: ввести вручную или войти через PSN, по желанию.
- Ключи привязки храним в защищённом хранилище Windows (DPAPI).

## 2. Ввод
- **Поток ввода:**
  - скрытое окно, которое получает только сообщения;
  - Raw Input для мыши и клавиатуры;
  - приоритет MMCSS «Games» и высокий приоритет потока;
  - высокоточный таймер на 1 мс; время по `QueryPerformanceCounter`.
- После каждой пачки событий мыши сразу пересчитываем стик: мыши на 8 кГц шлют события пачками.
- **Захват:**
  - включается клавишей (F8 по умолчанию);
  - курсор прячется и запирается (`ClipCursor`);
  - нажатия не уходят в другие окна: наше окно на переднем плане, а при необходимости
    подключаем LL-хук;
  - **защита фокуса:** окно потеряло фокус, захват снят или программа упала → все кнопки
    отпущены, стики в центре, на PS5 отправлено нейтральное состояние.
- Левые и правые Shift/Ctrl/Alt различаются.
- A+D одновременно: побеждает нажатая последней.
- Колёсико — нажатие длиной 60 мс.
- До 2 клавиш на одно действие.

## 3. Мышь → стик
Порядок обработки за один тик:

```
1. v      = сумма отсчётов за окно W мс / W                 (W = 2–32, по умолчанию 8)
2. v.y   *= соотношение Y/X;  инверсия Y по желанию
3. сглаживание: адаптивное (сильное на медленном движении, слабое на быстром), можно выключить
4. d      = |v| × чувствительность профиля
5. d      = кривая(d):  степенная d^exp  ИЛИ  LUT⁻¹ по калибровке (см. §4)
6. мёртвая зона игры: прыжок за порог (анти-мёртвая зона), включается плавно
   на самых малых скоростях; форма — круг (cos/sin угла) или квадрат (по осям)
7. остаток сверх 100 % наклона переносится на следующий тик (по желанию)
8. выход  = направление(v) × d,  круговой ограничитель |выход| ≤ 1
9. нет движения R мс → ровно центр, без «хвоста»
```

### Кривая через LUT
Игра крутит камеру нелинейно. Чтобы мышь ощущалась «как на ПК», применяем обратную кривую:

```
желаемая скорость поворота = чувствительность × скорость мыши
наклон стика = LUT⁻¹(желаемая скорость поворота)
```

LUT — это пары «наклон → °/с», между ними линейная интерполяция. Первая точка задаёт
мёртвую зону игры.

## 4. Калибровка
Два способа, оба работают прямо в игре:

**А. Живая настройка (как в GIMX).**
- Клавиша выбирает параметр: чувствительность, соотношение X/Y, мёртвая зона X/Y, форма,
  кривая, сглаживание.
- Колёсико мыши меняет значение.
- Текущее значение показывает панель в окне RplayPS. Результат сразу виден в игре на ТВ
  и сохраняется в профиль.

**Б. Замер LUT.**
- Программа держит стик на наклонах 0.1 … 1.0.
- Пользователь клавишей отмечает полный оборот камеры (ориентир снова в центре).
- Получаем °/с для каждого наклона и порог мёртвой зоны.

**Проверочные тесты (из GIMX):**
- **«Круг».** Программа сама ведёт виртуальную мышь по кругу. Прицел должен описать круг,
  а не овал или квадрат. Так проверяются соотношение осей и форма мёртвой зоны.
- **«Сдвиг».** Программа сдвигает виртуальную мышь туда и обратно на одинаковое расстояние.
  Прицел должен вернуться точно в исходную точку. Так проверяется линейность.

## 5. Профили и режимы
| Режим | Включение | Что меняется |
|---|---|---|
| Пешком | по умолчанию | свои настройки мыши и LUT |
| Прицел | автоматически, пока зажата ПКМ (L2) | свои настройки и LUT |
| Машина | клавишей | свои настройки; A/D наклоняют левый стик плавно, а не сразу на 100 % |
| Колесо оружия/радио | пока зажат Tab (L1) | мышь задаёт **направление** стика (по накопленному смещению) |

Профиль — это JSON-файл: раскладка, настройки мыши по режимам и LUT. Профилями можно делиться (`gta6.json`).

## 6. Интерфейс
- Небольшое окно: подключение к PS5, профили, раскладка, настройки мыши.
- **Визуализатор стика** и живая статистика: частота мыши, дрожание тика, отправка на PS5.
- Панель живой калибровки: какой параметр выбран и его значение.

## 7. Тесты
- Модульные тесты: скорость, форма мёртвой зоны, кривые, LUT, профили, раскладка.
- **Режим «без консоли»:** весь путь от мыши до стика с визуализатором, без PS5. Кривую
  можно отлаживать без консоли.

## 8. Открытые вопросы
- Настройки камеры в GTA 6: мёртвая зона, ускорение. Узнаем только в игре.
- Режим «машина»: определять автоматически, скорее всего, не получится, поэтому переключаем клавишей.
- Если chiaki-ng выпустит мышь-как-стик, сравнить подходы.
